# 몹 피해 다니기

2023년 6월부터 7월까지 혼자 만든 클라이언트·서버 프로젝트입니다. 몬스터를 피해 움직이는 게임에 서버 통신, 몬스터 경로 탐색, 플레이어 정보 저장 기능을 연결했습니다.

## 작업한 내용

- IOCP와 작업 스레드를 이용해 클라이언트와 서버가 통신하도록 구성했습니다.
- 몬스터의 현재 위치와 목표 위치를 타일로 바꾸고, A* 탐색 결과를 따라 이동 경로를 계산했습니다.
- MSSQL과 ODBC, 프로시저를 이용해 로그인 시 플레이어 정보를 불러오고 위치와 상태를 저장했습니다.
- 데이터 조회·갱신 구간의 잠금을 사용했습니다. 저장과 경로 탐색을 함께 처리하던 구조의 작업 분리와 잠금 범위는 개선이 필요한 부분입니다.
